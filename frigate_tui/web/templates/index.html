This dashboard has exact feature parity with the terminal UI because both are driven by the same FrigateMonitorCore.

Live updates arrive over SSE. Activity Log messages, health calculations, event ordering, and MQTT vs poll behavior are identical to the TUI.

Sound alerts (web only): every Frigate detection (MQTT events and timeline visible rows) is logged as Event: … and spoken via Chatterbox {label} on {camera} using the voice chosen in Settings (cached under localrecordings/). Otherwise MP3/WAV from sounds/ via web_alerts.sounds. Enable browser audio in Settings → Event alerts.
Use the tab bar to navigate. Poll interval, TTS voice, summary auto-refresh, and alert audio are in Settings.
Click any event row for snapshot + clip links (when available).
